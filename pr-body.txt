## Security Issues Fixed
1. **Unsafe Upload & Path Traversal (Upload Harden)**
   - Replaced client MIME type checking with robust server-side magic byte validation using ile-type.
   - Prevented path traversal vulnerabilities in the local fallback by using secure randomly generated file names.
   - Enforced hard 5MB size limit before reading to buffer.
   - Deleted obsolete upload/local/route.ts.
2. **Card Status Leakage**
   - Hardened 
/[uid] public NFC tap route to explicitly deny rendering of revoked and deactivated cards, presenting a safe 'Card Unavailable' screen instead.
3. **Analytics Spam**
   - pi/tap/route.ts now drops analytics requests for inactive/revoked/deactivated cards.
4. **Card Claim Guessing (Rate Limiting)**
   - Hardened card claims with authenticated user + IP rate-limiting (claimRatelimit) to prevent brute forcing of UIDs.
5. **Profile Deletion TOCTOU**
   - Reinforced the final DELETE SQL query in pi/profile to strictly require eq(profiles.userId, user.id).
